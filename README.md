# 🔐 Password Manager

A secure, client-side password manager built with **vanilla HTML, CSS, and JavaScript**.  
Store and manage all your passwords **locally**, with full offline functionality and strong security features — no external servers or cloud storage involved.

---

## ✨ Features

### 🔑 Password Generation
- Customizable length (4–50 characters)  
- Select character types: uppercase, lowercase, numbers, symbols  
- Option to exclude similar characters (0, O, l, 1, I)  
- Real-time password strength indicator  
- One-click password copy  

### 💾 Password Storage
- Encrypted local storage  
- Master password protection  
- Add, search, edit, and delete saved passwords  
- Notes field for extra information  
- Export/Import encrypted data  

### 🔒 Security
- Master password required at login  
- Lockout after 3 failed login attempts (1-minute cooldown)  
- Auto-lock timer options (5m, 10m, 30m, 1h)  
- Password visibility toggle  
- Fully offline — data never leaves the device  

### 🎨 User Interface
- Clean, modern, responsive layout  
- Light, Dark, and Auto color themes  
- Smooth animations  
- Mobile-friendly design  

### ⚙️ Extras
- Settings customization  
- Export/Import management  
- Clear all stored data  
- Session timeout handling  
- Built-in notification/toast system  

---

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)  
- **No installation required** — simply open the HTML file to start using the app  

---

## 🏁 Conclusion
This Password Manager offers a secure, private, and fully offline solution for managing sensitive credentials. With strong encryption, a master password system, and an intuitive UI, it ensures that your data remains safe, accessible, and entirely under your control.
